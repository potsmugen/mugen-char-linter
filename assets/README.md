# Application icon

`icon.png` and `icon.ico` were generated by the project maintainer using
Microsoft Copilot. The image is an intentionally distinct parody inspired by
the hairstyle of an existing character; no source artwork was intentionally
copied into the asset.

The applicable Microsoft Copilot terms were not independently recorded.
The project code is MIT-licensed; this note documents the provenance of the
image assets without making a separate licensing claim for them.
